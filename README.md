# KaWia: pobieranie aplikacji

Aplikacja KaWia na Androida (10 lub nowszy): kopia zdjęć i kontaktów w domu oraz okazje z OLX, Vinted i Allegro Lokalnie.

**Pobierz:** [KaWia.apk](https://github.com/wfirasiewicz-beep/KaWia-pobierz/releases/latest/download/KaWia.apk)

Do połączenia z domem potrzebny jest link zaproszenia `kawia://dolacz?...` od osoby, która ma serwer KaWia.
Bez niego aplikacja się zainstaluje, ale nie połączy.
