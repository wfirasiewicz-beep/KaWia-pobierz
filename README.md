# KaWia: pobieranie aplikacji

Aplikacja KaWia na Androida (10 lub nowszy): kopia zdjęć i kontaktów w domu, okazje z OLX, Vinted i Allegro Lokalnie, kalendarz rodziny.

**Pobierz aplikację:** [KaWia.apk](https://github.com/wfirasiewicz-beep/KaWia-pobierz/releases/latest/download/KaWia.apk)

Do połączenia z domkiem potrzebny jest link zaproszenia od osoby, która ma serwer KaWia.
Bez niego aplikacja się zainstaluje, ale nie połączy.

## Własny domek (serwer)

Wszystko, czego potrzeba do postawienia własnego, niezależnego domku KaWii z nową siecią Tailscale, jest w folderze [nowy-domek](nowy-domek):

- [INSTRUKCJA-nowy-domek.txt](nowy-domek/INSTRUKCJA-nowy-domek.txt): instrukcja krok po kroku,
- [KaWia-serwer-instalator.zip](nowy-domek/KaWia-serwer-instalator.zip): instalator serwera na Windows (bez instalowania .NET),
- [KaWia.apk](nowy-domek/KaWia.apk): aplikacja na telefony domowników.
